Accessibility Statement

Luxury Redefined Palm Beach is committed to making this website usable by the widest possible audience, including people with disabilities, consistent with the goals of the Americans with Disabilities Act (ADA) and the Web Content Accessibility Guidelines (WCAG) 2.1 Level AA.

We are working toward ensuring this site provides:

  • Text alternatives for images and visual content
  • Keyboard-navigable menus, forms, and interactive tools
  • Sufficient color contrast for readability
  • Clear, consistent navigation across every page

This is an ongoing effort. If you encounter any part of this site that is difficult to access or use, please let us know so we can address it — we take this feedback seriously and will work to fix genuine barriers promptly.
